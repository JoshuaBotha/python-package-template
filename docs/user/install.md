# Install

## Requirements

- Python 3.13+

## Add to a project

From a GitHub release tag:

```bash
uv add "my-package @ git+https://github.com/JoshuaBotha/my-package.git@v0.0.0"
```

Or download the wheel from the
[releases page](https://github.com/JoshuaBotha/my-package/releases).

## Upgrade

Change the tag in the install command and run `uv sync`.
